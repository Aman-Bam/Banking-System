About Backend-Ledger

Enterprise-Grade Financial Ledger & Banking System

Backend-Ledger is a full-stack financial application designed to manage digital bank accounts, execute secure money transfers with double-entry ledger verification, prevent double-spending with idempotency protection, and send automated transactional notifications.

1. Core Purpose

Financial software requires absolute transaction integrity, zero silent failures, and strict auditability. Backend-Ledger enforces double-entry accounting where every transfer generates balanced debit and credit ledger pairs ($Sum(Debits) = Sum(Credits)$).

2. Key Features

  • Secure Authentication: Custom JWT authentication with HTTP-only cookies and active MongoDB token TTL blacklisting on logout.
  • Multi-Account Management: Create and manage savings and checking accounts with real-time balance calculations.
  • Atomic Transfers & Double-Entry Ledger: Guaranteed financial correctness across all account transactions.
  • Idempotency Protection: Prevents duplicate transactions using unique idempotency request keys.
  • Automated Notifications: Instant transaction receipts powered by Nodemailer & Google OAuth2.
  • Audit Logs & Reconciliation: Full transparency with real-time audit trails and administrative reconciliation endpoints.

3. Tech Stack

Frontend: React 18, TypeScript, Vite, Tailwind CSS, TanStack Query, Zustand, Axios

Backend: Node.js, Express.js, MongoDB Atlas (Mongoose), Zod Schema Validation, Winston Logger
